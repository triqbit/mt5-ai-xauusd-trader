# Palette Journal - UX & Accessibility Learnings

## 2024-05-13 - Institutional Startup UX
**Learning:** For professional financial tools, a "silent" startup can feel unfinished or unreliable. Providing immediate, high-fidelity visual feedback via an ASCII banner and a formatted configuration table builds operator trust and ensures they are aware of the active risk parameters before trading begins.
**Action:** Always include a structured configuration summary and a distinct visual marker for system startup.
