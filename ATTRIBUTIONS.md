# Project Attributions

This project integrates multiple open-source components and relies on several third-party libraries. We are grateful to the following authors and projects for their contributions to the ecosystem.

## Core Integrated Repositories
- **PPO Implementation:** Inspired by [zero-was-here/tradingbot](https://github.com/zero-was-here/tradingbot) (MIT License).
- **Risk Management System:** Based on [ilahuerta-IA/mt5_live_trading_bot](https://github.com/ilahuerta-IA/mt5_live_trading_bot) (MIT License).
- **Neural Network Architecture:** Based on [CodeDestroyer19/Neural-Network-MT5-Trading-Bot](https://github.com/CodeDestroyer19/Neural-Network-MT5-Trading-Bot) (MIT License).
- **LSTM Implementation:** Based on [nguyenviettuan96/mt5_AI_trading_bot](https://github.com/nguyenviettuan96/mt5_AI_trading_bot) (Apache 2.0 License).
- **Trading Environment:** Based on [AminHP/gym-mtsim](https://github.com/AminHP/gym-mtsim) (MIT License).

## Major Dependencies
- **MetaTrader 5 Integration:** MetaTrader5 and MetaAPI Cloud SDK.
- **Machine Learning:** PyTorch, Stable-Baselines3, Gymnasium, Scikit-learn.
- **Data & Analysis:** Pandas, NumPy, TA-Lib, Pandas-TA, YFinance.
- **Database & Backend:** SQLAlchemy, Alembic, PostgreSQL (psycopg2), FastAPI, Uvicorn.
- **Monitoring & Visualization:** Prometheus, Dash, Plotly, Structlog, Rich.
