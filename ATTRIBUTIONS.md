# Project Attributions

This document lists third-party software and components integrated into the MT5 Trading Bot project, along with their respective licenses and original sources.

## Integrated Software Components

### Core Algorithms & Trading Logic
- **PPO & Dreamer V3:** Based on [zero-was-here/tradingbot](https://github.com/zero-was-here/tradingbot) (MIT License). Includes algorithm architecture and feature engineering.
- **Risk Management & 6-Layer Filter:** Based on [ilahuerta-IA/mt5_live_trading_bot](https://github.com/ilahuerta-IA/mt5_live_trading_bot) (MIT License). Includes entry filter system and state machine.
- **Neural Networks:** Based on [CodeDestroyer19/Neural-Network-MT5-Trading-Bot](https://github.com/CodeDestroyer19/Neural-Network-MT5-Trading-Bot) (MIT License). Includes model templates and indicator logic.
- **LSTM Models:** Based on [nguyenviettuan96/mt5_AI_trading_bot](https://github.com/nguyenviettuan96/mt5_AI_trading_bot) (Apache 2.0 License). Includes feature extraction pipeline.

### Environment & Simulation
- **MT5 Simulator:** Based on [AminHP/gym-mtsim](https://github.com/AminHP/gym-mtsim) (MIT License). Provides OpenAI Gym environment wrapper.
- **Expert Advisor Templates:** Based on [geraked/metatrader5](https://github.com/geraked/metatrader5) (MIT License). Provides MQL5 strategy templates.

### Performance & Optimization
- **GPU Acceleration:** Based on [Stefodan21/Forex-trading-bot](https://github.com/Stefodan21/Forex-trading-bot) (MIT License). Provides DirectML/GPU optimization logic.
