# Trade Signal Explainability

The MT5 AI/ML Trading Bot provides an institutional-grade explainability system to move away from "black-box" trading and toward transparent, auditable decision-making.

## Overview

Every trade signal generated by the ensemble is accompanied by a `SignalExplanation` object. This object decomposes the decision into several key dimensions:

- **Model Attribution**: How much each model (e.g., PPO, LSTM) contributed to the final vote, including dominance ratios.
- **Feature Cluster Contributions**: Quantitative and qualitative impact of different feature groups (Momentum, Trend, Volatility, Volume, Patterns).
- **Regime Context**: Market state at the time of the signal, including confidence and alignment scores.
- **Execution Summary**: Results of technical and operational filters (e.g., Spread, Momentum gates).
- **Risk Assessment**: Detailed risk management constraints, including Kelly-based sizing and R:R quality.

## Institutional Metrics

### Strategic Confluence Score
A holistic metric that represents the agreement between the ensemble signal and the market environment. It is calculated as a weighted average of:
- Model Confidence (40%)
- Regime Alignment (30%)
- Session Alignment (15%)
- Volatility Alignment (15%)

### Model Dominance
Identifies which model(s) drove the final decision based on their weighted confidence within the ensemble.

## Usage

### Generating an Explanation
```python
explainer = SignalExplainer()
explanation = explainer.explain(
    symbol="XAUUSD",
    direction=1,
    confidence=0.85,
    model_votes=votes,
    model_weights=weights,
    risk_data=risk,
    regime_info=regime
)
```

### Visualizing for Operators
The system supports high-fidelity terminal dashboards using the `rich` library.
```python
explainer.format_for_operator(explanation)
```

## Research Integration
Signal explanations can be converted into `StrategicConfluenceSection` objects for inclusion in institutional research reports.
