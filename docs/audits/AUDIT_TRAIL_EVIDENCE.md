## 🛠️ Implementation Details

The audit trail is implemented as a dedicated SQLite/PostgreSQL table (`audit_log`) using a robust SQLAlchemy 2.0 ORM model. Every critical decision point in `main.py` and `RiskManager` has been instrumented to record events with structured JSON metadata.

### Decision Chain Traceability
Unlike standard logging, the `RiskManager` now evaluates ALL risk layers for every signal, even if an early layer fails. This provides a complete vetting history for every signal, ensuring full compliance visibility into why specific trades were permitted or denied.

### Security & Privacy
The audit system implements automatic secret scrubbing for configuration snapshots, ensuring that credentials (`MT5_PASSWORD`, `TELEGRAM_TOKEN`, etc.) are never persisted in the audit database.
